# 前端界面设计

正式渲染端采用 Vue 3、Tailwind CSS 和 Ant Design Vue，定位为 Apple-inspired 桌面生产力应用。设计只借鉴克制的排版、留白和交互语言，不代表 Apple 官方设计或关联产品。

## 技术职责

- Tailwind CSS 负责页面布局、间距、排版、响应式和局部视觉状态。
- Ant Design Vue 负责表格、表单、选择器、分页、弹窗、抽屉、菜单、通知和加载反馈。
- `app/theme.ts` 统一配置 Ant Design Vue Token，`app/styles.css` 定义与之对应的 Tailwind Token 和少量跨组件规则。
- 平台图标和作品封面继续使用真实业务资源，不使用虚构产品摄影或装饰插画。

单次使用的简单布局直接使用 Tailwind。同一视觉组合出现三次以上时，才考虑提取真实组件或语义类。单个元素的工具类明显超过 10 至 12 个时，应重新检查组件边界，但不以缩短 class 为目的创建弱辅助函数。

## 视觉规范

- 页面画布使用 `#f5f5f7`，内容表面使用白色，正文使用 `#1d1d1f`。
- `#0066cc` 是浅色界面唯一的交互强调色；深色视频表面上的链接可以使用 `#2997ff`。
- 成功、等待和失败保留低饱和语义色，但不得用于普通按钮或导航。
- 页面和卡片不使用装饰渐变，不给按钮、文字或普通卡片添加投影。
- 18px 圆角用于内容卡片，11px 用于普通控件，完整胶囊用于操作按钮、搜索和顶部视图切换。
- 点击反馈使用短促的缩放或透明度变化；减少动态效果设置必须得到尊重。

## 应用结构

应用使用原生 Electron 标题栏，内容区顶部固定 64px 工具栏。中间通过“账号 / 作品 / 发布记录”切换主视图，右侧提供通知和账户入口。页面不重复显示可见标题，搜索、筛选和页面操作集中在内容顶部工具栏。

账号与发布记录使用中等紧凑的表格密度。作品页保留横竖封面混排的瀑布流。选择发布账号和编辑发布计划是两个独立弹窗：账号选择使用纵向作品列表，发布计划使用按平台分组的纵向配置卡片。

应用只面向桌面 Electron 窗口，主窗口最小尺寸为 900 × 600，不提供手机端信息架构。

## 旧界面废弃说明

旧版侧边栏、手写通用图标、全局渐变背景、厚重卡片阴影、手写表格/分页/下拉菜单以及超宽发布计划表格均已废弃。新功能不得依赖旧 class 或建立新旧视觉兼容层。

## 构建

前端改动的最低交付门槛是从仓库根目录执行完整生产构建：

```bash
nvm use
npm run build
```
