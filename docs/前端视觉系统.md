# 前端视觉系统

Electron 正式渲染层使用 Tailwind CSS 4、shadcn-vue `reka-vega` 组件源码和 Reka UI。`app/styles.css` 是全局样式入口，负责浅色语义 token、系统字体、基础页面状态和减少动态效果规则；项目不提供深色模式。

## 主题语义

- `background`、`card`、`popover` 表示页面与浮层表面，`foreground` 表示主要内容。
- `muted`、`muted-foreground` 表示次要表面与辅助文字，`border`、`input`、`ring` 表示边界和焦点。
- `primary` 保留原视觉系统的蓝色主色，`secondary` 和 `accent` 用于中性层级与选择反馈。
- `info`、`success`、`warning` 是项目扩展状态；错误状态统一使用 shadcn-vue 的 `destructive`。
- 所有状态同时定义对应 foreground，业务组件不直接写固定色值。

## 组件目录

- `app/components/ui/<name>/` 保存 CLI 生成的基础组件源码和 `index.ts`，只允许加入通用 variant 与必要类型。
- `app/components/<feature>/` 保存业务 Vue 组件、领域专属 TypeScript 配置和 `index.ts`。
- 业务布局、文案和接口状态不能进入 `components/ui`。
- 非平台图标使用 Lucide Vue，平台 Logo 使用 `app/public/platform-icons` 中的品牌资源。

## 交互约定

- 应用壳使用 Sidebar；桌面窗口常驻，窄窗口由 Sidebar 内置 Sheet 打开。
- `AppDialog` 组合 Reka Dialog，统一标题、描述、尺寸、操作区和阻塞行为。
- 危险操作使用 AlertDialog，不调用 `window.confirm`。
- 通知中心使用 Popover、ScrollArea、Alert 和 Badge，保留未读、逐条关闭与全部清空。
- 发布进度使用 Card、Progress 和 Collapsible，保持独立实时浮层。
- 发布账号选择使用 Popover Portal，不维护 `position: fixed` 坐标或滚动监听。
- 纯图标操作同时提供 Tooltip 和 `aria-label`；带文字按钮不重复提供 Tooltip。

## 数据与页面状态

- 账号表和发布记录表使用 TanStack Vue Table；编辑型发布计划表直接组合 shadcn-vue 控件。
- 列表首次加载使用 Skeleton 或明确的加载区域，局部提交使用 Spinner，无数据使用 Empty，可恢复错误使用 Alert。
- 日期与定时发布继续使用 Chromium 原生 `date` 和 `datetime-local`，外观由 Input 或等价语义样式承载。
- 作品页保留适配横竖封面的瀑布流布局。

## 动效与运行环境

- 只使用 Dialog、Popover、Sheet、Collapsible 等组件自带的进入和退出动效。
- 不维护页面转场、自定义 shimmer 或在线字体资源，并尊重 `prefers-reduced-motion`。
- 正式目标为项目当前 Electron 41 渲染环境；Vite 浏览器模式只用于开发预览。
