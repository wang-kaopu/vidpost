# 前端视觉系统

Electron 渲染层使用 Tailwind CSS 4 和 daisyUI 5。`app/styles.css` 是唯一的全局样式入口，只注册 Tailwind、daisyUI 和默认的 `maybeghost` plugin theme，不维护额外的 design tokens、组件覆盖或自定义动效。

## 组件约定

- 交互组件直接使用 daisyUI：`btn`、`input`、`select`、`textarea`、`checkbox`、`card`、`table`、`badge`、`alert`、`modal`、`drawer`、`dropdown`、`toast`、`progress`、`loading`。
- 允许使用 daisyUI 官方尺寸、状态和语义修饰类，例如 `btn-sm`、`btn-primary`、`badge-success`、`alert-error`。
- Tailwind utility 只负责布局、响应式、定位和必要的文字层级；颜色仅使用当前主题的语义色。
- 不建立 `app-*` 语义类，不覆盖 daisyUI 的圆角、边框、阴影、焦点和组件高度。
- 非平台界面图标使用 Lucide Vue，平台 Logo 继续使用 `app/public/platform-icons` 中的品牌资源。

## 页面结构

- 应用导航使用 daisyUI `drawer`。`lg` 及以上常驻，较窄窗口通过 `navbar` 中的按钮打开遮罩抽屉。
- 弹窗继续由 `AppDialog.vue` 管理原生 `<dialog>` 的焦点、Esc 和遮罩关闭行为，内容结构使用 `modal`、`modal-box` 和 `modal-action`。
- 通知、发布进度和作品选择反馈分别使用 `toast + alert`、`toast + card + progress`、`toast + alert`。
- 宽表格保留横向滚动和关键列定位，组件外观使用 daisyUI `table` 及官方修饰类。

## 唯一浮层定位例外

发布账号表格中的“添加账号”菜单需要越过表格和弹窗的滚动裁剪，因此保留基于触发元素视口坐标的 `position: fixed` 定位。该例外只负责坐标和尺寸，浮层内容仍使用 daisyUI `dropdown/menu`。
