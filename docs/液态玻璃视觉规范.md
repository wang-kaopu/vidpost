# 液态玻璃视觉规范

渲染进程采用 macOS 风格的分级玻璃材质。界面背景使用
`app/public/backgrounds/liquid-glass.webp`，组件通过半透明表面和
`backdrop-filter` 呈现背景色彩，不再使用大面积装饰性 CSS 渐变。

## 材质层级

- 薄玻璃：侧边栏和主内容面板，强调背景透射，模糊半径约 30–38px。
- 标准玻璃：输入框、数据列表和内容卡片，使用更高白色不透明度保证正文可读性。
- 厚玻璃：弹窗、通知中心、浮层和发布进度面板，模糊半径约 34–38px，并使用更明确的边缘高光。

玻璃表面统一通过白色半透明边框、顶部内高光和低强度环境阴影建立层级。业务内容卡不重复添加大面积投影，选中态通过系统蓝描边表达。

分区、表格行和弹窗页脚不使用单纯的灰色分割线，统一采用半透明白色高光边缘，并在高光内侧叠加极弱暗边模拟玻璃厚度与折射。输入框、卡片和选中态的完整轮廓不属于分割线，继续遵循各自的状态样式。

Sidebar 使用浅中性灰透明材质，主画布则叠加更高比例的乳白遮罩。二者之间不绘制实体分割线，而是通过透明度、饱和度和模糊半径的变化，加上边缘窄幅高光形成折射式分界。

Sidebar 菜单的悬停态和选中态使用同一档白色折射面。选中态由页面状态持续驱动，鼠标离开后仍保留背景、高光边缘和蓝色图标。

## 颜色与交互

- 唯一主交互色为系统蓝 `#0071e3`，按下或强调状态使用 `#0066cc`。
- 成功、警告和危险色只用于对应的业务状态。
- 按钮和图标按钮按下时缩放，不使用悬浮位移动画。
- 输入、表格和弹窗仍需保持足够的不透明度，避免背景明暗变化影响文字对比度。

## 圆角

- Sidebar 选中框是小型矩形控件的圆角基准，统一使用 16px。
- 按钮、输入框、选择框、文本域、下拉项和小型浮层均使用该基准。
- 头像、图标按钮、复选框、状态点和进度条保留圆形；状态标签、筛选标签和分页等明确的胶囊元素保留全圆角。
- 主面板、弹窗、通知和内容卡属于大型容器，继续使用 18–30px 的层级圆角。

## 背景资源

背景图为 1440×900 WebP。图片在构建前已做降饱和与强模糊处理，主画布再叠加约 91% 的乳白遮罩，让色彩只作为接近不可见的环境明暗存在。页面使用 `cover` 保持比例，窗口宽高比变化时允许裁切边缘，避免拉伸图像。
